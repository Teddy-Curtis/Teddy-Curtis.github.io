Reinforcement learning is an ML technique where a model learns how to interact with some environment with the aim of maximising a reward. This technique made history in 2018 when DeepMind's AlphaGo beat the current world champion at the game Go, for which you can refer to the excellent documentary [here](https://www.youtube.com/watch?v=WXuK6gekU1Y).


# Quick RL Overview

## States, actions and policies

A very basic example is called a k-armed bandit. In this, there are k options, or actions. If you choose an option, you get a reward that is found by randomly sampling from some probability distribution, which is different for each arm. An example is shown below. 


If we knew the probability of each arm then it would be trivial to define a policy that maximised our reward: the policy would always pick the arm with the highest expected return. However, generally we will not know exactly the distribution of reward for each action, and this is something that we have to learn.  

We can also think of a situation where we have *two* k-armed bandits, one denoted $s_1$ and another denoted $s_2$, which define our different *states*, and we pick an action from one state, then the other, repeatedly. If each k-armed bandit has a different set of action-reward probabilities, then our policy would also depend on the state.
